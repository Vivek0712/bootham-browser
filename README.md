# Minimal Electron Browser

A minimal Electron desktop browser application built using the min-browser library.

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

## Testing

```bash
npm test
```

## Project Structure

- `browser/` - Browser application code
  - `main.js` - Main process entry point
  - `renderer.js` - Renderer process script
  - `browser.html` - Browser UI
  - `*.test.js` - Test files
- `assets/` - Application assets
- `.kiro/specs/` - Feature specifications and design documents

## Requirements

- Node.js 16 or higher
- npm or yarn
